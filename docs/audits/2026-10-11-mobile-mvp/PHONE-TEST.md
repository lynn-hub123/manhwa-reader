## 怎么开始

1. 手机浏览器打开链接，用创建站点的同一个 ChatGPT 账号登录。不要向其他服务提供密码或验证码。
2. 等书架出现“离线资源已就绪”。没有就绪时先保持联网，记录提示文字，不按离线可用验收。
3. 用浏览器菜单的“安装应用”或“添加到主屏幕”。若没有选项，先在浏览器体验，并记录机型、系统和浏览器版本，不把安装计通过。
4. 从主屏幕入口重新打开并确认就绪，再用“选择文件”导入本机 PDF，按弹窗命名。第一次建议用小的、有3页以上的 PDF；封面可后续添加。

PDF、封面、书架、进度仅存在当前设备/当前网址；新HTTPS网址不会继承电脑localhost书架，也不会跨设备同步。保留原PDF；浏览器清理网站数据会删掉本地书架，持久化许可也不是永久保存承诺。

## 逐项验收

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 登录和加载 | 关闭后从主屏幕重新打开 | 不循环登录，能到书架；能显示离线资源已就绪 |
| 导入和阅读 | 导入小PDF，打开章节 | 显示真正的页面内容，不只是页码正确；按钮可触及 |
| 放大和平移 | 选200%，横向拖动，然后选适应宽度 | 可以读到最右侧；适应宽度回到可见且不留空白横向偏移 |
| 手势 | 单指上下滚动、普通倍率左右划、双指放大再回到起点 | 上下不误翻页；放大后的左右是平移；双指恢复起始倍率/fit，不被浏览器缩放抢走 |
| 续读 | 停在第2页中段，回书架，再开 | 真实第2页及页内位置恢复，不是1×1画布或错误正文 |
| 断网冷打开 | 确认就绪且PDF已导入；开飞行模式，关闭应用，再从主屏幕打开 | 书架/章节/实际PDF正文均可读，续读正确；不是保留旧页面的假离线 |
| 条漫与后台 | 对自己的高瘦条漫重复阅读/后台切回/断网 | 自然滚动、不误翻页；条漫百分比/位置恢复 |
