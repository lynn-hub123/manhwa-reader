# 当前画面推荐截图设计

## 目标

把现有的全手动“当前画面截图”升级为混合流程：系统先从当前可见漫画画面中推荐一个 `5:7` 封面构图，用户可以直接使用，也可以在推荐位置上继续调整。

## 用户流程

1. 用户在阅读器中点击“设封面”并选择“当前画面截图”。
2. 应用只分析此刻屏幕可见的已渲染漫画画布，不扫描整章，也不上传内容。
3. 应用生成一个固定 `5:7` 的推荐截图，并显示封面预览。
4. 预览提供“使用推荐”“调整一下”“取消”。
5. 选择“调整一下”后，推荐框保留原位置；用户可拖动或缩放，比例始终锁定为 `5:7`。
6. 调整工具提供“保存为封面”“恢复推荐位置”“取消”。
7. 保存时从 PDF 的原始 canvas 像素裁切高清 JPEG，而不是截取低清屏幕。

## 推荐规则

- 在当前可见 canvas 与阅读区交集内生成多个 `5:7` 候选框。
- 优先选择信息覆盖率高、明暗变化适中、边缘细节较多、大片纯白或纯黑较少的候选。
- 对过于贴边的构图做轻微惩罚。
- 若画面不足以生成正常候选，使用可见区域内居中的最大 `5:7` 框作为回退，并继续允许调整。
- 第一个版本不引入人物识别模型或外部 AI 服务。

## 交互与状态

- 推荐计算期间显示“正在分析当前画面…”，避免看起来像按钮失效。
- 预览必须明确标注“系统推荐”，并保持现有夜间/日间主题样式。
- 调整模式同时支持鼠标与触摸/触控笔，统一使用 Pointer Events。
- 调整框不可越过被选中的漫画 canvas 可见边界。
- `Escape` 与“取消”均退出且不修改现有封面。
- 当前没有可见漫画 canvas 时提示“当前画面还未加载完成”，不进入截图界面。
- 保存失败时保留原封面并显示错误提示。

## 不在本次范围

- 扫描整章寻找封面。
- 人脸、人物或对白气泡识别。
- 多个推荐结果之间切换。
- 修改既有的“上传本地图片”“文字封面”“从候选页选择”流程。
